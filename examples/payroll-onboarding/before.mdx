# Activate payroll

Our powerful onboarding API makes it easy to activate payroll instantly. Create your company and send an onboarding request. When you receive a successful response, the company is fully activated and ready to pay employees.

Use your API key to submit onboarding. You can retry any request safely if your connection fails. Webhooks keep you updated in real time, so you never need to check status manually.

The sandbox behaves exactly like production. Once your test request succeeds, you are ready to launch.
