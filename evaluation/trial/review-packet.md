# First real-platform trial preparation

The [freeze record](freeze.json) identifies the framework pinned before target-platform inspection. The source was refreshed for role-based wording and clear onboarding before any private trial. [The procedure](README.md) preserves baseline/revised evidence, original evaluations and comparison limits. Plan/results remain blank templates; the wider rubric is provisional.

The local pack builder archives that exact Git commit, checks critical file hashes and adds separately identified trial instructions/templates. It makes no model/network calls and does not collect platform inputs. It preserves existing output files. Top-level pack metadata identifies the frozen source; preparation records inside that source are historical snapshots.

The [pack record](pack-record.json) identifies the generated ZIP and checks actually performed; it is not a trial result. Original fictional evaluation inputs, findings and their hashes are preserved. Active guidance can evolve independently of those archived reviews.

A trial owner can run the portable pack privately with one real workflow and its relevant spec/source/current-doc revisions, chosen agent/build commands and available answer owners. No platform content or result is committed by this preparation, and no numerical pass threshold or publication gate is introduced.
